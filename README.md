# Melodyn

Voice-first Musikstream: Du sagst, wonach dir ist, Melodyn erzeugt passende Songs und lernt aus deinem Feedback.

## Prototyp ansehen

Öffne `web/index.html` im Browser. Die Seite hat drei Bereiche:

- **Produkt**: Showcase bzw. Landingpage
- **App-Prototyp**: klickbarer Stream mit Chat, Player, Bibliothek, Geschmacksprofil und Abo-Ansicht
- **Konzept**: Architektur, Datenmodell, Lernregeln, Kosten, Roadmap, Risiken

Mistral und ElevenLabs sind im Prototyp nur simuliert. Der Sound ist ein kleiner Demo-Synth im Browser (`web/app.js`).
